CarbonX – AI Powered Carbon Prediction App

Overview

CarbonX is a mobile application prototype that predicts carbon footprint using a regression-based AI model.

How It Works

User Data → Backend → ML Model → Database → Personalized Insights

Tech Stack (Proposed)
	•	Frontend: Figma Prototype
	•	Backend: Python + Flask
	•	ML Model: Linear Regression
	•	Database: Firebase
